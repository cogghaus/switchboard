Route each task to the right specialist.

Switchboard is a Claude Code plugin that turns your main session into an orchestrator. You set direction; it patches each task through to the best-fit specialist sub-agent, at the model that gives the best result per token, and hands the work back reviewed.

The operating loop

You are the operator at the board

Every substantial task runs the same six-step loop. You keep the thinking that compounds; the specialists carry the volume and the depth.

01

Frame

Restate the goal in one line, catching a bad framing early.

02

Decide

Direct for small work; delegate what is large or specialized.

03

Route

Pick the specialist and the model from the routing matrix.

04

Delegate

Brief by goal, file paths, constraints, acceptance criteria.

05

Review

Never relay a sub-agent's output unread; verify what matters.

06

Report

Plan, then what was done, then results and what remains.

The board

Thirteen lines, each a specialist

Every agent is a standalone sub-agent with its own tools and its own default model. Route a task to the line whose role fits.

Get started

Install in two steps

Install by name from the marketplace, then confirm the inventory. You should see 13 agents and 4 skills.

Add the marketplace

Register the Switchboard marketplace with Claude Code.

claude plugin marketplace add cogghaus/switchboard

Install and verify

Install the plugin by name, then check the inventory. You should see 13 agents and 4 skills.

claude plugin install switchboard@switchboard
claude plugin details switchboard

Start delegating

Give your session a real task. The orchestrator loop auto-invokes on substantial work; to enter it deliberately, call it by name. Then set up the extras below.

# enter the orchestrator loop on demand
/orchestrator-loop
Make it yours

Set it up for how you work

Three optional steps, each its own skill. All are reviewed and reversible; none change what any agent actually does.

standing default

Always-on mode

Auto-invocation is best-effort. Add the opt-in per-user SessionStart hook to make the orchestrator loop your standing default on every session. Per-user, so it never affects teammates.

Set up the hook
/theme

Theme the roster

Keep the plain corporate roster, or name any subject and each role is reskinned to a fitting character. Cosmetic only: names change, tools and models and safety do not.

How theming works
/wireup

Wire into a project

Connect the roster to one codebase: convention hooks and project MCP servers written into the project's own config, as a reviewed, merge-safe overlay. Credentials stay env-var references.
